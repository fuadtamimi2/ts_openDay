# Open Day Registration System

Full stack project built with React + TypeScript + Node.js.

Features:
- Student registration
- Admin login
- Admin dashboard
- MongoDB database
- REST API

Tech stack:
Frontend:
React + Vite + TypeScript

Backend:
Node.js
Express
MongoDB
Mongoose

Run backend:

cd backend
npm install
npm run dev

Run frontend:

cd vite-project
npm install
npm run dev
